## Connection to the WOC problem

The WOC app prototype provides fields for employee name, department, expense amount, and category. Its confirmation screen shows the submitted information and requests that a supporting receipt be attached within 24 hours. This is a **receipt reminder**, not evidence of a working receipt-upload function or automated reconciliation.

The employee directory is a separate generic demonstration of using a Google Sheets data source in an app. It may inform future structured data-management ideas, but was not built as a WOC accounting directory.

## Final presentation use
Present the current expense documentation problem from Lab 2, then show the WOC app screenshot as a possible employee-facing digital intake step. Explain that real implementation would require secure storage, validation, access rules, receipt attachment, and integration with accounting systems.
